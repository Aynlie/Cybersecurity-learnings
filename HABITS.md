# 🔁 Weekly Habit Tracker

Four things, tracked lightly. This isn't about perfect streaks — it's
about never letting more than a few days pass without touching each
one. Matches the 90-Day Roadmap's "weekly floor" system: **3 focused
sessions minimum per week**, even in a brutal CSIA week.

---

## The Four

| Icon | Habit | What Counts |
|---|---|---|
| 🐙 | **GitHub Commit** | Any real addition to this repo — a writeup, notes, a fix. Not just README edits. |
| 🏠 | **TryHackMe** | One room, or meaningful progress on one, per session. |
| 🚩 | **CTF** | One PicoCTF (or other) challenge attempted — solved or not, if you learned something, it counts. |
| 📖 | **Cyber Article** | One article/blog post/writeup read and one sentence noted on what it taught you. |

## Rules (keep it simple)

1. **Minimum day** — if you have zero time/energy, one small thing
   still counts: read one article paragraph, glance at one THM room,
   look at one CTF challenge title. Something is a session; nothing
   is a skipped day.
2. **Never miss twice in a row.** One skipped day is a normal week.
   Two in a row is the pattern that kills momentum — if it happens,
   do a minimum-day session immediately.
3. **Commit small, commit often.** A three-line note committed today
   beats a polished writeup committed never. Polish later, in a
   follow-up commit.
4. **Log first, judge later.** Don't skip logging a day because it
   felt like "not enough." The tracker is for pattern-spotting, not
   grading yourself.
